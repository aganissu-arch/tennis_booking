# Tennis Appointment System (ระบบนัดหมายเล่นเทนนิสรายวัน)

เว็บแอปพลิเคชัน Single-Page สำหรับจัดคิวลงชื่อเล่นเทนนิส ออกแบบสไตล์ Professional & Clean รองรับการใช้งานบนมือถือ (Mobile-First) พัฒนาด้วย **Streamlit** และรองรับฐานข้อมูล **Google Sheets** พร้อมระบบป้องกัน Rate Limit

---

## ฟีเจอร์หลัก
- **ระบบประกาศสถานะสนามประจำวัน (Daily Announcement)**:
  - แสดงสถานะการจองสนามเด่นชัดด้านบน: **ยืนยันแล้ว**, **รอยืนยัน**, **งดเล่น**
  - ระบุหมายเลขคอร์ท (เช่น คอร์ท 1, 2) และช่วงเวลาเล่น (เช่น 18:00 - 20:00 น.) พร้อมข้อความประกาศเพิ่มเติม
  - กรณี "งดเล่น" ระบบจะปิดรับการลงชื่อชั่วคราวเพื่อป้องกันความสับสน
- **ช่องทางชำระเงินพร้อมเพย์ (QR Code)**: แสดง PromptPay QR Code ด้านล่างของหน้าเว็บและในหน้าต่างแนบสลิป เพื่อให้ผู้เล่นสแกนจ่ายเงินได้สะดวกรวดเร็ว
- **ระบบอัปโหลดและตรวจสอบสลิปโอนเงิน (Payment Slip)**:
  - ผู้เล่นสามารถกดปุ่ม **"แนบสลิป"** เพื่ออัปโหลดหลักฐานการโอนเงิน
  - เมื่ออัปโหลดแล้ว ระบบจะเปลี่ยนสถานะเป็น **"ชำระแล้ว"** ให้ทันทีอัตโนมัติ
  - ผู้ดูแลหรือสมาชิกในก๊วนสามารถกดปุ่ม **"ดูสลิป"** เพื่อเปิดดูภาพสลิปที่แนบไว้ได้
- **Google Sheets Cloud Database (พร้อม Smart Caching)**:
  - บันทึกข้อมูลขึ้น Google Sheet ข้อมูลคงอยู่ถาวร ทั้งรายชื่อผู้เล่นและการตั้งค่าสนามประจำวัน
  - มีระบบ Cache ข้อมูลอัจฉริยะ ป้องกันปัญหา Google API Quota Exceeded (Error 429) ทำให้เปิดเว็บได้รวดเร็วและไม่ติด Rate Limit
- **Professional & Clean UI (Emoji-Free)**: ดีไซน์ระดับพรีเมียม สไตล์สโมสรกีฬา British Green ไร้ Emoji ออกแบบให้อ่านง่าย สบายตา สัมผัสง่ายบนหน้าจอมือถือ
- **ลงชื่อได้เฉพาะวันนี้เท่านั้น**: ล็อกการจองแบบวันต่อวัน เพื่อความคล่องตัวและป้องกันการจองคลาดเคลื่อน
- **จำกัด 6 ท่านต่อวัน**: ควบคุมจำนวนผู้เล่นไม่ให้เกิน 6 คน
- **ระบบคำนวณและหารค่าสนามอัตโนมัติ**: กำหนดยอดรวมค่าสนาม ระบบจะหารเฉลี่ยและแสดงยอดที่ต้องชำระต่อคนทันที
- **Popup ยืนยันรายการ**: มีหน้าต่างเด้งยืนยันก่อนบันทึกหรือยกเลิกการจอง
- **ระบบ Fallback สำรองในเครื่อง**: สลับไปใช้ SQLite อัตโนมัติหาก Google Sheets มีปัญหาชั่วคราว

## โครงสร้างไฟล์สำหรับอัปโหลดขึ้น GitHub

```text
tennis/
├── app.py                      # ซอร์สโค้ดหลักของแอปพลิเคชัน
├── requirements.txt            # รายการไลบรารีที่จำเป็น (streamlit, gspread, google-auth)
├── README.md                   # เอกสารคู่มือโปรเจกต์
├── .gitignore                  # กำหนดไฟล์ที่ห้ามอัปโหลด (เช่น secrets.toml, ฐานข้อมูลในเครื่อง)
├── assets/
│   └── promptpay_qr.jpg        # รูปภาพ QR Code สำหรับชำระเงิน
└── uploads/
    └── slips/                  # โฟลเดอร์จัดเก็บรูปสลิป
```

## วิธีการนำขึ้น Streamlit Community Cloud (Deploy)

1. นำไฟล์ทั้งหมดขึ้น GitHub Repository ของคุณ (ยกเว้นไฟล์ `.streamlit/secrets.toml`)
2. เข้าไปที่ [share.streamlit.io](https://share.streamlit.io) แล้วกด **New app**
3. เลือก Repository และตั้งค่า Main file path เป็น `app.py`
4. ไปที่ **Advanced Settings > Secrets** แล้วนำข้อความจาก `.streamlit/secrets.toml` ในเครื่องไปวาง
5. กด **Deploy** จะได้ลิงก์สำหรับแชร์ให้สมาชิกใช้งานทันที
